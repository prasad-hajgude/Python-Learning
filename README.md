## 💡 Key Concepts (Quick Reference)

### Variables
```python
name = "Prasad"
age = 23
salary = 35000.00
is_student = True
```

### Data Types
```python
print(type("hello"))   # <class 'str'>
print(type(25))        # <class 'int'>
print(type(3.14))      # <class 'float'>
print(type(True))      # <class 'bool'>
```

### F-Strings
```python
name = "Prasad"
age = 23
print(f"My name is {name} and I am {age} years old.")
```

### Operators
```python
a, b = 48, 24
print(a + b)   # Addition → 72
print(a // b)  # Floor division → 2
print(2 ** 6)  # Exponent → 64
print(19 % 5)  # Modulus → 4
```

### Type Conversion
```python
age = int("25")        # str → int
price = float("99.9")  # str → float
text = str(100)        # int → str
```
